# 🐍 Gemini Neon Snake

A high-octane, classic Snake game enhanced with AI-powered commentary and a neon-noir aesthetic. Built with React, Tailwind CSS, and the Google Gemini API.

## 🚀 One-Click Deployment

Since your code is already on GitHub, you can deploy this for free in seconds:

### Option 1: Vercel (Recommended)
1. Go to [Vercel](https://vercel.com).
2. Connect your GitHub account.
3. Select this repository and click **Deploy**.
4. **Environment Variables:** In the Vercel dashboard, add a variable named `API_KEY` with your Google Gemini API key if you want to use the AI features outside of the sandbox.

### Option 2: Netlify
1. Go to [Netlify](https://app.netlify.com).
2. Click **"Import from GitHub"**.
3. Select this repository and deploy.

## 🛠 Features
- **AI Arena Master:** Dynamic arena names generated by Gemini.
- **Real-time Commentary:** Gemini reacts to your wins, losses, and high scores.
- **Neon Aesthetics:** A polished, dark-mode UI with glowing effects.
- **Responsive Controls:** Play with WASD or Arrow keys.

## 🔑 AI Integration
The game uses the `@google/genai` SDK. In this environment, the `process.env.API_KEY` is handled automatically. For local development or custom deployments, ensure you have a valid API key from [Google AI Studio](https://aistudio.google.com/).
